# hero-text-centered

Custom **hero** block. Purpose: Top-of-page campaign message with a centered heading, supporting paragraph and primary calls to action.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row with a background image; then one cell holding an H1 heading, a paragraph and one or more CTA links (each link alone in its own paragraph so it becomes a button).
