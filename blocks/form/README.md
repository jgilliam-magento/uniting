# form

Custom **form** block. Purpose: Mailing-list signup form collecting name, email and postcode.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per field with cells Label | Type | Name | Placeholder | Required | Group; a 'submit' row whose label is the button text; optional two-cell settings rows: action (submission URL), method, success (thank-you message), error.

## Supported variations

No variations.
