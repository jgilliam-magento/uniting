# cards-promo-overlay

Custom **cards** block. Purpose: Side-by-side campaign promo tiles, each with text and a CTA overlaid on a darkened full-bleed photo.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: first cell: background image; second cell: heading, paragraph and a CTA link.
